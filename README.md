# IT3040_Assignment1_IT23818552
Playwright automated tests for IT3040 Assignment 1 - Singlish to Sinhala transliteration system.

# project overview
This project contains automated tests written using **Playwright** to validate the functionality of a Singlish to Sinhala transliteration tool.  
The tests ensure that Singlish input is correctly converted to Sinhala script.


# Install dependencies
npm install

# Run all Playwright tests
npx playwright test

# Show test report
npx playwright show-report

# Tools & Technologies
- **Playwright** – for end-to-end automation testing  
- **Node.js** – runtime environment  
- **JavaScript** – programming language for tests  
- **Git & GitHub** – version control and repository management
